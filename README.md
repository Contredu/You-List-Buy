## 🇪🇸 Español

### 📝 Descripción
**You-List-Buy** (Control de Stock y Compras Familiar) es una aplicación web orientada a optimizar la gestión del hogar. Su objetivo principal es facilitar 
el control de inventario de la despensa, coordinar listas de compras mensuales compartidas, administrar el presupuesto familiar y mantener un registro 
histórico de precios para mejorar la toma de decisiones financieras.

### ✨ Características Principales
*   **Gestión de Despensa:** Control detallado y actualizado del inventario del hogar.
*   **Listas Colaborativas:** Creación y gestión de listas de compras mensuales compartidas.
*   **Control Presupuestario:** Seguimiento de gastos y visualización del histórico de precios con gráficos interactivos.
*   **Integración de IA:** Funcionalidades impulsadas por Google Gemini para asistencia inteligente.
*   **Progressive Web App (PWA):** Instalable en dispositivos móviles para una experiencia nativa y fluida.

### 🛠️ Tecnologías Utilizadas
*   **Frontend:** React 19, Vite, Tailwind CSS v4.
*   **UI & Visualización:** Motion (animaciones), Recharts (gráficos), Lucide React (íconos).
*   **Backend:** Node.js, Express, TypeScript, esbuild.
*   **Infraestructura & Datos:** Firebase.
*   **Inteligencia Artificial:** Google Gen AI SDK.

### 🚀 Instalación y Uso

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/Contredu/You-List-Buy.git](https://github.com/Contredu/You-List-Buy.git)
    cd You-List-Buy
    ```
2.  **Instalar las dependencias:**
    ```bash
    npm install
    ```
3.  **Configurar las variables de entorno:**
    Crea un archivo `.env` en la raíz del proyecto e incluye las credenciales necesarias (Firebase, API Keys de Google, etc.).
4.  **Iniciar el servidor de desarrollo:**
    ```bash
    npm run dev
    ```
5.  **Construir para producción:**
    ```bash
    npm run build
    npm run start
    ```

## 🇬🇧 English

### 📝 Description
**You-List-Buy** (Family Stock and Shopping Control) is a web application designed to optimize household management. Its main goal is to facilitate pantry inventory tracking, coordinate shared monthly shopping lists, manage the family budget, and keep a historical record of prices to improve financial decision-making.

### ✨ Key Features
*   **Pantry Management:** Detailed and up-to-date tracking of household inventory.
*   **Collaborative Lists:** Creation and management of shared monthly shopping lists.
*   **Budget Control:** Expense tracking and price history visualization with interactive charts.
*   **AI Integration:** Smart features powered by Google Gemini.
*   **Progressive Web App (PWA):** Installable on mobile devices for a seamless, native-like experience.

### 🛠️ Tech Stack
*   **Frontend:** React 19, Vite, Tailwind CSS v4.
*   **UI & Data Viz:** Motion (animations), Recharts (charts), Lucide React (icons).
*   **Backend:** Node.js, Express, TypeScript, esbuild.
*   **Infrastructure & Data:** Firebase.
*   **Artificial Intelligence:** Google Gen AI SDK.

### 🚀 Installation and Usage

1.  **Clone the repository:**
    ```bash
    git clone [https://github.com/Contredu/You-List-Buy.git](https://github.com/Contredu/You-List-Buy.git)
    cd You-List-Buy
    ```
2.  **Install dependencies:**
    ```bash
    npm install
    ```
3.  **Set up environment variables:**
    Create a `.env` file in the root directory and add the necessary credentials (Firebase, Google API Keys, etc.).
4.  **Start the development server:**
    ```bash
    npm run dev
    ```
5.  **Build for production:**
    ```bash
    npm run build
    npm run start
    ```
